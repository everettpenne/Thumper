# Thumper 1.0.0

Thumper is now one app for podcasts, reading and music. The old Baliset player is folded in: the same Thumper player screen, mini player,
notification and Up Next serve all three tabs.

## Three libraries, one player

- **Listen** — podcast feeds and downloaded episodes, unchanged.
- **Read** — RSS articles, unchanged.
- **Music** — albums and songs from the phone, including AIFF/Apple Music folders, and optionally a Jellyfin server.

The tabs browse sources; they do not own playback. Starting anything sets the one queue, and switching tabs never interrupts it. The
queue can hold an episode and a song, and Up Next shows whatever is next.

## Music

- Local library from Android's media index or a folder granted through the system picker; AIFF/AIFC are read by the app's own extractor.
- Album identity, folder/embedded artwork and a music-specific player layout: cover, title, artist/album, previous/next track, shuffle
  and the shared sleep timer. Podcasts keep show notes, speed and skip-by-seconds.
- **Crossfade** (off, 3, 5, 8 or 12 seconds) and **volume leveling** with a measure command, both music-only.
- **Jellyfin**: sign in to a server, browse albums and songs, stream the original files, and download them with progress, retry and
  delete. The token is encrypted at rest and sent in an `Authorization` header, never in a URL; downloaded songs play with the server off.
  Plain http is allowed for a server at home, with a warning on the sign-in screen.

## Under the hood

One `PlaybackService`, one `MediaSession`, one queue. Two ExoPlayers sit behind the session: the active one plays, and the idle one starts
the next track under the last seconds of the current one when both are music. The session switches to it when the fade ends. Podcasts
never crossfade. The AIFF extractor, gain processor and Jellyfin OkHttp source moved into the shared service.

## Verified

- **115 JVM tests pass**, including the existing feed/parser/library tests, the merged queue, AIFF/ID3, gain processing and the Jellyfin
  API and mapping.
- Local music: scanned 11 songs, played an album, and a 3-second crossfade moved from Paper Moon to Aster Vale in the same player.
- Jellyfin against a local mock server: sign-in, albums/artwork, streaming through the shared player, three downloaded tracks, and
  playing a download with the server stopped.
- R8 release build: local music, Jellyfin sign-in/albums and the player all run with shrinking enabled.
- Podcast playback metadata and the same service were exercised; the emulator had no DNS during the final check, so a real episode
  stream could not be confirmed here.

## Limits and migration

- Music playlists, the Baliset library check and MusicBrainz cover lookup are not ported yet.
- Only the first Jellyfin music library on a server is shown; Jellyfin is direct-play only (no transcode fallback).
- Jellyfin downloads run while Thumper's process is alive, not as a background download service.
- Baliset is a separate package. Local music is rescanned, and Jellyfin is signed in again; Baliset playlists, measurements and downloads
  do not move automatically.
- Thumper 1.0.0 is signed with the same key as 0.9.0 and installs over it, keeping podcast subscriptions, reading state and settings.
