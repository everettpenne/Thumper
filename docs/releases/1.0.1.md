# Thumper 1.0.1

Music saved on the phone, read properly.

## Fixes

- **Album covers for AIFF music.** A library from Android's media index addresses each song by number, so Thumper never saw the ".aiff" in its name and read AIFF files' covers with Android's own reader, which cannot find them: on a library of AIFF files (an Apple Music or iTunes export) nearly every album showed a placeholder. Thumper now knows AIFF by the song's own file name and type and reads the cover from the file. Tap **Scan again** in Music once to fill the covers in.
- **Android 12.** Reading the phone's music there needs the older storage permission, which Thumper now asks for; before, the library came back empty.
- **Declining the permission** now says so, and points to choosing a folder instead, rather than doing nothing.
- **Not music:** ringtones, alarms, notification sounds and voice recordings are left out of the library. If Android's audio list comes back empty while its index is still catching up, Thumper reads the same files from the index directly.

## Install

Install over 1.0.0; your library, queue and playlists stay. Signed with the same key as every Thumper release.
